# Size & DEX

`SizeBreakdown` and `DexInfo` are summable (`+`), so bundle classes aggregate base + splits. Available via
[`ApkFile.size_breakdown`][apkfile.ApkFile.size_breakdown] / [`ApkFile.dex_info`][apkfile.ApkFile.dex_info]
(and the equivalent, bundle-summed properties on every bundle class).
